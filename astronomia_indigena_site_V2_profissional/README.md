# Astronomia Indígena no Brasil — V2

Projeto em HTML/CSS/JavaScript para abrir no VS Code.

## Como executar
1. Abra esta pasta no VS Code.
2. Instale a extensão Live Server.
3. Abra `index.html`.
4. Clique em `Go Live`.

## Dados e fontes
- MAST: pesquisas e ações de Astronomia Cultural, Guarani Mbya, Tikuna e Tembé.
- IBGE: mapa baseado na API de malhas territoriais.
- Wikimedia Commons: imagens com atribuição/licença indicada nas páginas dos arquivos.

## Observação
O mapa depende de conexão com a API do IBGE. As imagens da galeria são carregadas do Wikimedia Commons para preservar a atribuição e evitar redistribuir arquivos sem necessidade.
